## 🎯 El mensaje central — automatización completa

**Esto es lo que vende NuncaCierro:**

> Un negocio que NUNCA CIERRA. Que tiene su propio sitio web profesional y un asistente que responde WhatsApp 24/7. El cliente consulta horarios, precios, agenda citas o pide domicilio **sin que el dueño tenga que estar pegado al celular**.

### Pilares del mensaje:

| Pilar                     | Cómo decirlo                                                                   |
| ------------------------- | ------------------------------------------------------------------------------ |
| **Sitio web profesional** | "Tu negocio en internet, bien presentado, adaptado a celular y computador"     |
| **WhatsApp integrado**    | "Cada visita puede convertirse en un mensaje directo a tu WhatsApp"            |
| **Automatización**        | "Respondé preguntas frecuentes automáticamente. Sin estar esclavizado al chat" |
| **Disponible siempre**    | "Mientras dormís, el sitio trabaja por vos. 24/7. Nunca cerrás"                |

### El eslogan clave:

> **"NuncaCierro — Tu negocio abierto 24/7 con sitio web + WhatsApp"**

Sin texto en pantalla.

y optimista. Sin texto en pantalla.
